# Documentation – German and English

The current feature overview and the complete version history are available in
German and English. Descriptions of modules, installation, clients,
and publication are also included in both languages.

- German: Heimserver_Manager_Funktionsuebersicht.txt und Heimserver_Manager_Versionsaenderungen.txt.
- English: en/Home_Server_Manager_Features.txt and en/Home_Server_Manager_Version_History.txt.
- Installation of the current package: RELEASE_INSTALLATION.txt or en/RELEASE_INSTALLATION.txt.
- All descriptions together: Documentation_<Version>_DE_EN.zip in the release.

Individual module descriptions contain older development states and explain
the introduction of a function at that time. Dated sections are historical
tips; for the current overall state, use the recent entries from the feature overview,
version history, and the current interface.
Historical limitations will not be retroactively removed from the history.

Technical file names, commands, and unchanged outputs of external programs
remain in their original form. English documentation files are located under
docs/en in the source package. The actual license texts remain unchanged;
translated explanations do not replace them.
